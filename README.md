My Java Repository!

This repository contains a collection of My Java classwork activities focused on various programming concepts, including employee information systems, GUI applications, and a final lab project. Each activity showcases different skills and techniques used in Java programming.

CLASSWORK ACTIVITIES:

✓ LabActivity1EmployeeInformationSystem.java

- Description: Implements the basic structure for an employee information system. This activity covers class creation, object instantiation, and simple data management.
- Key Concepts: Classes, Objects, Methods, Basic Input/Output.

✓ LabActivity2EmployeeInformationSystemPart2.java

- Description: Expands on the first lab by adding additional features to the employee information system, such as data validation and enhanced user interaction.
- Key Concepts: Advanced data handling, error checking, and user prompts.

✓ LabActivity3ConditionalStatement.java

- Description: Demonstrates the use of conditional statements (if-else, switch) to control program flow based on user input.
- Key Concepts: Conditional Logic, User Input, Decision Making.

✓ LabActivity4EmpInfoSystemGUI.java

- Description: Introduces a graphical user interface (GUI) for the employee information system, improving usability and user experience.
- Key Concepts: GUI Design, Event Handling, AWT/Swing.

✓ LabActivity5QuizAppAWT.java

- Description: A quiz application built using AWT. It allows users to answer questions and provides a score at the end.
- Key Concepts: GUI Development, Event Listeners, Application Logic.

✓ LabActivity6SwingToDoList.java

- Description: A to-do list application developed using Swing, allowing users to add, remove, and display tasks.
- Key Concepts: Swing Components, List Management, User Interaction.

✓ MyMidtermLabExam.java

- Description: A comprehensive Java program that serves as a midterm exam, incorporating concepts learned from previous activities.
- Key Concepts: Integration of multiple Java concepts, problem-solving, and coding best practices.

✓ finallabprojectcalculator.java

- Description: A calculator application that performs basic arithmetic operations. This final project showcases a complete application structure.
- Key Concepts: User Interface, Arithmetic Operations, Application Structure.

✓ review_gavino.py

- Description: A Python script designed for reviewing or summarizing key concepts from the Java activities. It may help in understanding the transition from Java to Python.
- Key Concepts: Python Basics, Comparison of Programming Languages.
